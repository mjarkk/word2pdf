# One path per line, relative to the tree root; '#' starts a comment.

# The code modules are the ones defining the libraries linked into word2pdf, as computed by
# gbuild's static linking (workdir/Dep/LinkTarget/Executable/word2pdf.d.{libraries,statics,
# externals} of a build). Everything not listed (Calc, Impress, Base, the desktop application,
# icon themes, translations, help, ...) is left out; gbuild skips missing modules in an
# extracted tree (see patches/0004-gbuild-extracted-trees.patch).
